# Dataset

Folder ini menyimpan data dan metadata dataset. Ini berbeda dari `database` aplikasi.

- `raw/`: salinan asli dataset yang tidak diubah.
- `processed/`: data turunan seperti crop wajah, hasil kurasi, atau manifest split.
- `metadata/`: CSV/JSON manifest, label, dan pemetaan identitas.

Jangan mengunggah dataset wajah atau CSV yang memuat nama/NIM ke repositori publik. Jangan edit sumber asli IMSFD; simpan hasil olahan di `processed/`.
